# data/instances

Generated by `tools/generate_instances.py` from the `Instances` sheet of
`tools/Machiavelli Roguelike.xlsx`. Edit the sheet, not these.
The generator rewrites every `.tres` in this folder and leaves this file alone.

## Writing an Effect

The sheet's **Effect** column says what an instance *does*. It is a list of
commands separated by `;`, run left to right:

```
discard choose 2; draw 2
```

The **Type** column decides *when* the commands happen:

| Type | Commands that act on a player | Rules (energy, draw_bonus, coins_per_card, open_decks, cost FILTER V) | destroy |
| --- | --- | --- | --- |
| **Reveal** | once on each player's turn in the round it is revealed | in force during those turns ("this turn") | once, when it is revealed |
| **Ongoing** | at the start of every player's turn for the rest of the match | in force for the rest of the match | at the start of every round |

Every instance affects **every player**, the same way, on their own turn.

### Commands

| Command | What it does | Example |
| --- | --- | --- |
| `draw N` | Draw N cards from your own deck. | `draw 2` |
| `draw_joker N` | Take N of your jokers from your deck (or its discard pile) into your hand. | `draw_joker 1` |
| `discard PICK [FILTER]` | Hand cards go to your discard pile. | `discard random 1` |
| `give PICK [FILTER]` | Hand cards go to the next player's hand. | `give choose 2` |
| `jumble PICK [FILTER]` | Hand cards become a random rank and suit. | `jumble random 2` |
| `cost PICK [FILTER] ±D` | Hand cards cost D more (`+`) or less (`-`) energy, for good. Never below 0. | `cost random 2 -1` |
| `cost FILTER V` | Rule: cards matching FILTER cost V energy. | `cost rank=7 0` |
| `energy +N` | Rule: +N energy (may go past the cap; `-N` takes it away). | `energy +3` |
| `max_energy +N` | +N max energy for the rest of the match. | `max_energy +2` |
| `draw_bonus N` | Rule: draw N more cards whenever you draw. | `draw_bonus 1` |
| `coins_per_card N` | Rule: +N coins for each card you play from hand. | `coins_per_card 1` |
| `open_decks` | Rule: the top card of every deck is face up. | `open_decks` |
| `destroy combo random` | A random group on the table — never the instance's own combo — goes to the discard pile(s). Nothing happens when no other group is on the table. | `destroy combo random` |

**PICK** says which hand cards:

- `random N` — N random cards. Within one instance, later `random` picks take
  *other* cards ("2 random cards … and 2 other random cards").
- `choose N` — the player picks N cards (a **Confirm** button appears for you;
  enemies pick the cards they can best spare). Play waits until it is settled.
- `all` — every matching card.

**FILTER** (optional, any number) narrows the cards: `rank=7` (or `rank=A`,
`J`, `Q`, `K`), `suit=hearts` (`diamonds`, `clubs`, `spades`), `joker`,
`natural` (not a joker). For example `discard random 1 suit=spades`,
`cost joker 3`, `cost rank=K suit=hearts 0`.

Upper or lower case doesn't matter.

### Safety rules

- `discard` and `give` never take a player's last card, so no instance can end
  a match on its own.
- A `choose` or `random` asking for more cards than fit takes what there is.
- Destroyed cards go to their owner's discard pile. A combo card (from no one's
  deck) goes to the discard pile of the player whose turn it is, and is theirs
  from then on.

### When an Effect is wrong

`python3 tools/generate_instances.py` refuses an unknown command and names the
row. The game reads each Effect in full when a match starts; a row whose Effect
is empty or doesn't read stays out of the pool, with a warning saying exactly
what is wrong. `tests/smoke_test.gd` fails if any row in the sheet doesn't read,
and plays every instance in real games.
